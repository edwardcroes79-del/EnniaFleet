title: FleetCommand — Vehicle Inventory Management
---

## Vision
A responsive web application for small-business fleet owners (5–30 vehicles) to track vehicles, employees, assignments, maintenance, fuel, incidents, and documents with role-based access.

## Design
- **Dominant:** Graphite navy `#1E293B` / slate-800 — authority and field-service precision.
- **Ground:** Warm off-white `#F8FAFC` — readable data surfaces.
- **Accent:** Amber `#F59E0B` — warnings, status highlights, primary action energy.
- **Semantic:** Emerald for success/available, rose for overdue/damage, blue for in-progress.
- **Typography:** Archivo (headings), IBM Plex Sans (body), JetBrains Mono (data/IDs/mileage).
- **Style direction:** Industrial-utility, dense-but-readable tables, color-coded status chips, sidebar navigation.

## Features
- Dashboard with fleet status, alerts, and recent activity
- Vehicle, employee, and assignment management
- Maintenance, fuel, and incident tracking
- Document storage with Supabase Storage
- Reports and filtered search
- Role-based auth (Admin, Director, Employee)
- Notifications for service, insurance, registration, license expiry
